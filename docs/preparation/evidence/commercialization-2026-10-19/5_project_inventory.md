## 5. Security and quality

### Takeaway
Engineering process is strong (design → plan → TDD → CI → manual runs), but an independent review on 18/10 found 3 high and 16
medium defects; the three high ones are still present in the code at HEAD, and since 19/10 there is no automated backend test
against real Postgres/Redis.

### Cited Findings
- Independent review of Bước 0–4 (18/10/2026): 3 high (all reproduced by probes), 16 medium (11 reproduced), ~55 low; good news: no cross-learner privacy hole found, every `/v1/admin/**` route has `@RequirePermission`, job lease framework correct, admin access token in memory and refresh token `httpOnly` cookie, no XSS sink or open redirect — [2026-10-18-buoc-0-4-code-review.md](docs/superpowers/reviews/2026-10-18-buoc-0-4-code-review.md) "Kết luận ngắn". The review file and its evidence folder are untracked (`git status` `??`).
  - C1 (high): idempotency handler runs outside the key-holding transaction; with the default 10-connection pool, 10 concurrent idempotent writes → all 10 return 500 after ~5 s; an expired key lets the handler run twice (duplicate writes). Still present: `runIdempotent` calls `await handler()` without passing `tx` — `apps/api/src/common/idempotency/idempotency.service.ts`; `PrismaPg` is created with only `connectionString` (no pool max/timeout) — `apps/api/src/common/db/prisma.module.ts`.
  - C2 (high): every distinct `timezone` spelling is cached forever (~29 KB each), so a learner can grow API memory without bound. Still present: unbounded `Map` in `apps/api/src/common/time/local-date.ts` L1–12; validation only checks `Intl` accepts it — `apps/api/src/identity/profile/timezone.ts`.
  - C3 (high): 500 errors are not logged; plus admin never shows `operation_id` (T10). Still present: `ProblemDetailsFilter.catch` builds the response with no logger call — `apps/api/src/common/problem-details/problem-details.filter.ts` L16–39.
  - Medium examples: T1 rejected revisions can still be published; T2 batch revert deletes entries learners depend on; T5/T14 lookup scans every learner's private words (36 → 798 ms with 300,000 private words); T6 distractors may yield two correct answers (logic unchanged after `5c8a731`); T7 practice "all" source 1,267 ms vs < 1 s budget; T8/T9 admin logout/refresh error handling; T12 IP rate limit with default `TRUST_PROXY=false` puts everyone behind a proxy in one bucket (registration 5/hour for the whole system) — same review, summary table.
  - No later commit or Bước 4 doc references C1–C3/T-findings (grep of Bước 4 decisions/design/delivery returned nothing); `git log -- <those files>` shows last changes predate the review.
  - Hygiene: untracked root file `.verify-b25-accounts.md` contains password/token/secret lines and is not in `.gitignore` (per review "Tài liệu và quy trình"; not opened in this investigation).
