## 2. Lookup feature (`LK/*`)

### 2.1 Page structure (`LK/LookupPage.tsx`)

### 4.3 AddWordSheet flow (`AddWordSheet.tsx`), step by step
Views: `'find' | 'manual' | 'edit' | 'picker'` (35).
1. **Open**: with a word (`initialWord`) the Từ field is pre-filled, no autofocus (358); `lockedGroupId` fixes the deck.
2. **Find**: fields "Từ" (`maxLength 100`) and optional "Câu bạn gặp (không bắt buộc)" (`maxLength 300`). `useLookup(lemma)` (`add-word-api.ts:33-42`): key `['lookup', word.lower()]`, `GET /v1/lookup?q=…`, enabled when 1..100 chars, staleTime 60 s → `{senses[], via_inflection[{kind, base{entry_id,lemma,pos}, senses[]}]}` (no debounce: fires on every change of the trimmed text; the Từ box is controlled, so each keystroke is a new key).
3. **Choose sense**: `options` = own senses + senses via inflection; `radiogroup aria-label="Chọn nghĩa"` (377), native `<input type=radio>` inside `<label>`; the `PronunciationLine` sits outside the label (comment 382-383); a sense already in the locked deck shows "Đã có trong nhóm" and no radio (A14-2, waits for `useGroupQueue(locked,'all')`). First pickable is the default (94). Header line "went là quá khứ của go" (`formOf`). No match → "Wordmet chưa có từ “…”. Tự nhập nghĩa để lưu." (361).
4. **AI** (see 4.5): shown when no options, or after link "Không phải nghĩa bạn cần?" (`ai.notThis`).
5. **Choose group**: `deckField` (214-242): locked → text "Lưu vào nhóm: {name}"; no decks → "Bạn chưa có nhóm nào…" + `[Tạo nhóm đầu tiên]`; else a button (sr label "Lưu vào nhóm: ") showing the deck (last-used from `localStorage 'wordmet-web.last-group'` if it still exists, `last-group.ts:2-18`) or "Chọn nhóm" → `view='picker'` (GroupPicker, 4.6). Locked deck: extra disclosure "Thêm nhiều từ theo chủ đề" (`byTopic`, A14-7) → topic + level `Select`s + `Link` "Xem từ" to `/{locale}/app/topic?code=&level=&group=` (490-511).
6. **Save**: button text `t('save', {word: senseWord})` = `App.addWord.save` "Lưu {word}" (473-477), shown when `chosenSense && !noDecks`. `senseWord` = the sense's own lemma for a sense chosen from the AI result, else the typed text (96). `submit()` validates: empty word → `wordRequired`; manual without meaning → `meaningRequired` (switches to manual view); no deck → `deckRequired`. `useSubmitOnce` makes one `POST /v1/quick-add` per press with `Idempotency-Key: {key}:add` (a new deck is created first: `POST /v1/groups {name}` key `{key}:deck`, via `useGroupMutations().createGroup`). Body shapes (117-138): `{group_id, sense_id[, sentence]}` | manual `{group_id, new_word:{lemma, meaning[, form_of:{entry_id,kind}][, ipa]}[, sentence]}` | AI `{group_id, new_word:{lemma, meaning, pos?, level?, topics?, form_of?, examples, ipa?, ai_suggestion:true}}`. Response `QuickAddResult{item_id,sense_id,created_item,created_word,sentence_id}`.
7. **After save**: `writeLastGroup`, toast `saved` ("Đã lưu từ “{word}” vào nhóm “{group}”."), invalidate `GROUPS_KEY, ['group'], ['items'], ['word'], ['words'], ['lookup']`, `onClose()`. Errors by problem slug: `private-word-exists` (+ link "Mở từ này" to the word), `group-full`, `private-word-limit-reached`, `sentence-limit-reached`, locked-deck 404 → checks `GET /v1/groups/{id}`: gone → `deckGone` ("Nhóm này không còn.") with only `[Đóng]`; else generic.
8. Footer in find view: `[Hủy]` (ghost), `[Nghĩa khác, tự nhập]` (quiet, when options>0; "Tự nhập nghĩa" when none or lookup error), `[Lưu {word}]` (sticker). Manual view: `[Quay lại]` + `[Lưu từ]` (`saveManual`), fields Từ, Nghĩa, Phiên âm (optional, hint "Không bắt buộc."), Câu, deck. Edit view: `EditSuggestionForm` + deck + note, `[Hủy]` (back to find, keeps AI result) + `[Lưu từ]`.
